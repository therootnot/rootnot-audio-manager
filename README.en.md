Download, install, update and uninstall Rootnot Audio plugins in one application. Move plugin cards around a zoomable canvas, review release notes and choose the version you want to install.

## Features

- Version history with complete release notes.
- In-app package downloads, integrity checks and temporary installer cleanup.
- Format and installation folder selection for compatible packages.
- Plugin license agreement shown before installation.
- Detection of installed plugins and backups of known user preset folders before changes.
- Animated logo, procedural connections and optional canvas animation.
- Built-in playlist with playback, seeking and volume controls; autoplay is off.

Supported products: **Octavion**, **rot** and **Geiger Core**. Available formats and components depend on the product and installer version. Geiger Core supports VST3, CLAP and Standalone; Octavion and rot support VST3 and Standalone.

## Download

The first public Manager release is being prepared. Installers will appear in this repository's [Releases](https://github.com/therootnot/rootnot-audio-manager/releases). The currently prepared application version is **0.9.14**.

Once a release is available, download its `.exe` installer and follow the installation steps. A separate .NET installation is not required.

An internet connection is required to fetch the version catalog and download updates. Installed plugins and the built-in player remain available offline. Plugins work independently of the Manager window. No GitHub account is required to access public releases.
